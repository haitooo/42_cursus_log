SITE-A

The site on port 8080. Its root is ./www, configured in conf/default.conf.

Static content

  • /static/ — a listing of a directory under this site (autoindex on)
  • /listing/ — a listing of a location with a root of its own
  • /nothing-here — 404, served from the page named by error_page

Routing

  • /old — a 301 redirect (return)
  • /upload/ — what has been uploaded. POST stores a file here, DELETE removes it

CGI

  • /cgi-bin/hello.py — Python
  • /cgi-sh/hello.sh — shell
  • /cgi-pl/hello.pl — Perl
  • /cgi-exe/greeting.bin — a compiled CGI of our own
  • /cgi-bin/cwd.py — the directory it runs in, and the file beside it opened by a bare name
  • /cgi-bin/hang.py — a CGI that never answers. Killed by its deadline, answered 504

Session

  • /session — sets a cookie, then recognises the same session on every later visit

The other port

  • SITE-B (port 8081) — a different site, with a root of its own
